The CoffeeMachine

Two classes. Three methods. One call.

by Dylan Gorrah & Liyema Masala

01

The task

Create two classes. One holds the main method. The other holds three methods.

Each of those three methods prints one Starbucks coffee item. Then call one method from main, so a single item prints on screen.

Hint: look up the Starbucks menu and pick three items.

02

Requirements

  • Two classes
    One holds the drinks. One holds the program.
  • One main method
    It lives in the second class, not the drinks class.
  • Three methods, three drinks
    Each one prints a different drink. No maths, no returns, no parameters.
  • Call one of them from main
    You will need an object first. Only one drink gets ordered.
03
